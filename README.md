# 損益分岐点シミュレーター (Break-Even Point Simulator)

直感的な操作で損益分岐点（Break-Even Point）を計算し、グラフで視覚的に確認できるウェブベースのシミュレーターです。

## 特徴
- **リアルタイムシミュレーション**: 売上高、売上原価（変動費）、販管費（固定費）のスライダーを動かすだけで、即座に利益や損益分岐点が計算されます。
- **グラフィカルな分析**: Chart.jsを用いて、売上高、総費用、固定費の推移と損益分岐点を折れ線グラフで分かりやすく表示します。
- **経営指標の可視化**: 限界利益率、損益分岐点比率、安全余裕率などの重要な指標を自動計算・表示します。
- **レスポンシブデザイン**: Tailwind CSSを使用し、PC・スマートフォン問わず見やすいデザインを提供します。

## 使用技術
- HTML5
- JavaScript (Vanilla)
- [Tailwind CSS](https://tailwindcss.com/) (CDN使用) - スタイリング
- [Chart.js](https://www.chartjs.org/) (CDN使用) - グラフ描画

## 使い方
1. 本リポジトリをダウンロード（またはクローン）します。
2. フォルダ内の `index.html` をお使いのウェブブラウザ（Google Chrome, Safari, Edge等）で開きます。
    - ※特別なサーバー環境（Node.jsなど）は不要です。
3. 画面左側のスライダー（または入力制）で「現在の売上高」「売上原価 (変動費)」「販管費 (固定費)」の数値を調整します。
4. 各種指標（営業利益、損益分岐点売上など）と右側のグラフがリアルタイムに連動して変化します。

### シミュレーション時の注意事項
※ 本シミュレーターでは、構造を分かりやすく示すために「売上原価＝変動費」「販管費＝固定費」と簡略化して扱っています。
